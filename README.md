# Friendslop Motel

Кооперативный прототип в жанре «френдслоп» (Unity 6, Netcode for GameObjects, 1–8 игроков по LAN/IP): игроки — персонал придорожного мотеля.

Прототип целиком сделан ИИ-агентами (Claude) под руководством человека — для лекции по геймдизайну.
