# Карточки (строго по порядку)

## C0 — Каркас
- `git init`, Unity `.gitignore` (Library, Temp, Logs, UserSettings, Build, *.csproj, *.sln, .vs). Удалить `Assets/TutorialInfo`, `Assets/Readme.asset`.
- Пакеты в `manifest.json`: `com.unity.netcode.gameobjects` (2.x, последняя совместимая с 6000.6), `com.unity.multiplayer.playmode` (если не резолвится — пропустить, отметить в ответе).
- `tools/check.ps1`: Unity `C:\Program Files\Unity\Hub\Editor\6000.6.3f1\Editor\Unity.exe -batchmode -nographics -projectPath <корень> -executeMethod Friendslop.EditorTools.Builder.BuildAll -logFile Logs/check.log -quit`; затем ищет в логе `error CS` / `Exception` / отсутствие `[BUILDALL OK]` → печатает `CHECK FAIL` + строки ошибок, иначе `CHECK OK`.
- `tools/build.ps1`: аналогично, `-executeMethod Friendslop.EditorTools.Builder.BuildWindows` → `Build/Friendslop.exe`.
- Пустой `Builder` (BuildAll пишет `[BUILDALL OK]`, BuildWindows собирает сцены из Build Settings), `GameConfig` + asset.
- `Docs/DECISIONS.md` с заголовком.
DoD: `CHECK OK`, коммит `[C0]`.

## C1 — Меню, сеть, игрок
- Сцена `Menu`: IMGUI — ник, IP (по умолч. 127.0.0.1), «Создать», «Подключиться», выход. NetworkManager (UnityTransport, порт 7777, max 8) переживает смену сцен; host загружает `Motel` через NetworkSceneManager.
- Сцена `Motel`: пока пол + свет + точки спавна.
- Префаб игрока: капсула со «лицом» и цветом по clientId, ник над головой (NetworkVariable), FPS-контроллер (WASD, мышь, Shift бег, CharacterController), камера только у владельца, Esc — курсор/выход в меню.
- Хост: кнопка «Начать смену» в лобби-состоянии → `GameState` (NetworkBehaviour) фиксирует число комнат (10/20 по числу игроков).
DoD: два билда/два окна на одном ПК видят друг друга и двигаются. → **Плейтест №1** (человек).

## C2 — Мотель и руки
- Builder генерирует локацию по GDD: лобби, стойка, доска ключей (20 слотов), стопка бланков, склад со стеллажами (бесконечный источник предмета), стойка швабр/кувалд, налоговый терминал, коридор с 20 номерами (дверь-проём, кровать, табличка-текст над дверью, точка пятна). Номера 11–20 закрыты стеной-заглушкой, если комнат 10.
- Система рук: `ItemType`, взаимодействие лучом 2.5 м, подсказка «E — …», E/G/ЛКМ по GDD, предметы на полу — NetworkObject (спавн/деспавн сервером).
- Интерфейс `IInteractable` (сервер решает, что делает E с предметом в руках).
DoD: можно взять/бросить/передать предметы, у клиента всё синхронно.

## C3 — Номера, деньги, налоги, задачи
- `Room`: состояния Ready / Occupied / NeedsService; при NeedsService — случайный набор недостающего + 40% пятно. Занос предмета в номер (E у точки/кровати), уборка шваброй (держать 3 с). Табличка показывает статус.
- `GameState`: касса (старт 150), счёт налога каждые 8 мин (100), оплата на терминале, дедлайн 3 мин → Game Over (экран для всех, хост — «Заново»).
- HUD: касса + таймеры слева, список задач справа (собирается из состояний номеров/стойки/драк/счёта).
- Деньги на полу: взял → +сумма в кассу.
- Для теста: временно все номера стартуют NeedsService.
DoD: можно привести номер в Ready, оплатить налог, проиграть.

## C4 — Гости (core loop замкнут)
- NavMesh (NavMeshSurface, запекается в Builder). `Guest` (сервер, NavMeshAgent, NetworkTransform) — капсула другого цвета.
- Спавнер: интервал из GameConfig (≤4 игроков 15±10 с, >4 — 8±5 с).
- Заселение: очередь у стойки, ожидание 30 с, бланк → подпись 2 с → ключ готового номера (ключ с доски) → идёт в номер. Живёт 30–50 с (>4 игроков 20–40 с) → номер NeedsService → идёт выписываться, ждёт 30 с: обслужили → игроку ключ и деньги; нет → роняет оба. Ключ на доске возвращается E по доске.
- Неплательщик 20%: на выписке уходит, не платя (помечен над головой «!» только после отказа).
DoD: полный цикл гость → деньги → обслуживание → новый гость. → **Плейтест №2 (core loop)**.

## C5 — Кувалда и драки
- ХП НПС 3, удар кувалдой (ЛКМ, кулдаун 0.6 с, луч 2 м) — по НПС и по игрокам. 0 ХП → лежит 5 с → уходит (роняет деньги, если должен).
- Ударенный НПС агрессивен: догоняет и бьёт ударившего (1 удар/с). Игрок: 5 ударов от НПС → без сознания 5 с (камера на полу, ввод заблокирован), гость сбегает без оплаты. Удар кувалдой от игрока по игроку: 1 удар → без сознания 1 с.
- Драка: раз в ~90 с два живущих гостя дерутся в коридоре, −5 $ / 5 с, пока оба на ногах.
DoD: можно положить неплательщика и забрать деньги, драка в списке задач. → **Плейтест №3**.
