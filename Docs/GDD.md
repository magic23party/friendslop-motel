# Friendslop Motel — GDD прототипа (рабочее название)

Цель: проверить core loop кооп-мотеля. Не красота, не баланс — работает ли «весело-хаотично вместе».

## Платформа
Unity 6000.6.3f1, URP, Windows, клава+мышь, русский UI. Сеть: Netcode for GameObjects, Host/Join по IP (LAN), порт 7777, до 8 игроков. Камера от 1-го лица.

## Core loop
Гость приходит → ресепшен заселяет → гость живёт → выезжает, платит → номер надо обслужить → номер снова готов. Деньги общие, налоги регулярно забирают часть. Игра бесконечна, проигрыш — неуплата налога.

## Старт
Меню: ник, «Создать» (host), «Подключиться» (IP). Хост жмёт «Начать смену» — число комнат фиксируется: 1–4 игрока → 10, 5–8 → 20 (комнаты 11–20 заперты при ≤4). Опоздавшие могут подключиться и после старта.

## Локация (одна, генерируется кодом)
Лобби с ресепшеном (стопка бланков, доска с ключами всех номеров), налоговый терминал, склад (стеллажи: полотенца, мыло, салфетки; стойка со шваброй и кувалдами), коридор(ы) с номерами. В номере: кровать, табличка на двери со статусом/списком нужного, точки под расходники и пятна.

## Поток гостей
Цель — контролируемый хаос. Новый гость: 1–4 игрока — каждые 15±10 с, 5–8 — каждые 8±5 с.

## Руки
В руках 1 предмет: бланк, ключ, полотенце, мыло, салфетки, швабра, кувалда, деньги. E — взять/отдать/положить, G — бросить на пол, ЛКМ — использовать (швабра держать, кувалда удар).

## Ресепшен
1. Гость встаёт у стойки, ждёт 30 с (иначе уходит, денег нет).
2. Игрок даёт бланк → гость расписывается (2 с) → игрок даёт ключ **готового** номера с доски → гость идёт в номер.
3. Живёт 30–50 с (5–8 игроков: 20–40 с), затем идёт к стойке выписываться, ждёт 30 с. Обслужили (E) → ключ и деньги в руки игроку (ключ вешается на доску, деньги в кассу автоматически при взятии). Не обслужили → бросает ключ и деньги на пол и уходит.
4. Неплательщик (20%): на выписке отказывается платить и уходит. Положить его кувалдой → выпадают деньги.
Ключ, лежащий не на доске, — номер выдать нельзя.

## Обслуживание номера (после выезда)
Случайный набор недостающего: 1–3 из {полотенце, мыло, салфетки} (каждый пункт отдельным заносом). С шансом 40% — пятно грязи (швабра, держать ЛКМ 3 с). Всё сделано → номер «Готов».

## Драки и кувалда
- У каждого НПС 3 ХП, снимает только игрок (1 удар = 1 ХП). 0 ХП → лежит 5 с, потом уходит из мотеля (деньги роняет только выехавший из номера — неплательщик или гость на выезде; побитый до выезда — ничего).
- Ударенный НПС агрессивен: бьёт ударившего. 5 ударов по игроку → игрок без сознания 5 с, гость сбегает, не заплатив. ХП игрока не показывается.
- Удар кувалдой по коллеге: 1 удар → без сознания 1 с. Хаос — фича жанра.
- Драка: раз в ~90 с два живущих гостя дерутся в коридоре. Пока драка идёт, −5 $ каждые 5 с. Положить обоих зачинщиков → драка кончается.

## Деньги и налоги
Старт 150 $, гость платит 50 $. Каждые 8 мин выставляется счёт 100 $. Оплатить: подойти к терминалу, E (нужно ≥100 $ в кассе). Не оплачено за 3 мин → проигрыш (экран «Мотель закрыт», время смены, заработано). Хост может перезапустить.

## HUD
Слева сверху: касса, таймер до налога / до дедлайна счёта. Справа сверху: общий список задач отеля (гость у стойки, номер N: мыло/полотенце/грязь, драка в коридоре, счёт не оплачен). Центр: прицел + подсказка «E — …». Над игроками — ник.

## Все числа
В одном `GameConfig` (ScriptableObject) — чтобы крутить баланс без кода.

## Вне прототипа (сознательно)
Голосовой чат, анимации и рэгдоллы, звук, прогрессия/апгрейды, сохранения, Relay/Steam, оптимизация.
